# Catalog snapshots are NOT copies of websites

This initial release stores a dated metadata/abstract record only, not an archived HTML/PDF page, photograph, intercepted message, or captured RF signal. `metadata_sha256` authenticates our *own abstract field*; it is **not** a hash of the original webpage.

For future source snapshots, record: discovery date; final URL; publisher; title; authors; retrieved time; access method; robots/terms decision; license; exact reusable components; checksums of legitimately retained artifacts; canonical link; and change history.

Do not archive full articles, images, PDFs, datasets, or source code unless the publication license or permission supports that use; otherwise maintain source links and original notes. Classified, leaked, proprietary, personally sensitive, private-intercepted, or targeting-relevant content is out of scope.
