# Lesson 26 — Public records and source criticism

## Goal

Build a dated, attributable claim from a public historical intelligence record without confusing an archive description, an institutional history, or a later interpretation with the underlying document.

## Activity

Choose one route in [the public records guide](../docs/military/PUBLIC_RECORDS_WORKFLOW_v06.md): NARA RG 457, NSA historical releases, the UK National Archives' intelligence guide, CSE's history, or ASD's historical account. Record the source identifier, creator, date, repository or publisher, release context, and the exact claim the record supports.

If using a finding aid, label the result `official-finding-aid-description`. If using an agency history, label it `institutional-self-description`. Use `document-observed` only after opening and checking the specific document.

## Explain

State one bounded claim, its evidence status, one alternative interpretation, and what remains unsearched. Distinguish a record created by a predecessor organization from one later held by another agency. Do not turn an archival gap into proof of absence or a historical record into a claim about current capability.

## Assessment

Grade the source path (25%), accurate attribution (25%), evidence status (20%), scope and gaps (20%), and clear citation (10%). Public availability does not grant republication rights; link to the source unless reuse is established.
