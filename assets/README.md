# Original educational graphics

These SVG diagrams were newly authored for Signal Atlas and do not reproduce a source chart or copyrighted photograph. The spectrum graphic depicts generic band categories, not a real allocation table. The generic processing diagram does not describe current military interception systems.

- `identity.svg` — branded cover artwork
- `spectrum_atlas.svg` — band-name visual reference
- `evidence_graph.svg` — claim provenance relationships
- `receiver_chain.svg` — conceptual synthetic/authorized learning flow
