# Ingested findings from the prior Deep Research report

**Status:** research architecture blueprint summarized, **not an independently run full crawl**. The prior report's principal recommendation was a pipeline of discovery -> rights-aware harvesting -> metadata -> verification -> knowledge graph -> human/agent interface. It proposed a portable GitHub schema and human-readable diagrams. Those are integrated into the existing Atlas foundation.

This edition extends that architecture with:
- A dedicated science division and formal literature catalog.
- Direct DOI/arXiv/PDF links and per-paper rights status.
- Original diagrams and PDF science briefs.
- Separate candidate knowledge-discovery notes and local source traceability.
- A dry-run-first, license-allowlisted retrieval helper for an Internet-enabled workstation.

**Limits:** The earlier report is a planning synthesis, not 1:1 verification of every source or license. This build did not crawl the Web continuously and did not fetch the third-party full PDF bytes. Prior proposed timelines are not commitments. A later-dated November 3, 2026 announcement identified in the earlier research cannot be used as an already-published source on November 2.

**Review checkpoint:** Before every version, verify document access, deduplicate, retain rights proofs, open actual PDFs and verify figures/equations where available, run local validations, and check navigation for non-specialists and agents.
