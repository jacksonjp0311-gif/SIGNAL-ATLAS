# The Science Division

**Goal:** Build an evidence-grounded map of physical laws, signal mathematics, measurement methods, computer models and published research. Every research idea has both a **human explanation** and a **machine-readable citation path**.

Start here: [Physics](01_wave_physics.md) · [Signal mathematics](02_signal_mathematics.md) · [Research synthesis](03_knowledge_discovery.md) · [Literature map](04_literature_map.md) · [Research-to-validation workflow](05_experiment_design.md)

[Documents and actual PDF briefs](../../documents/README.md) · [Publication catalog](../../documents/INDEX.md) · [Original diagrams](../../assets/README.md)

**Subjects:** electromagnetic field propagation, energy, frequency and wavelength, Fourier duality, sampling, Nyquist, aliasing, noise, SNR, bandwidth, information theory, inverse problems, uncertainty, Bayesian claims, repeatable experiments and science/AI intersections.

We distinguish broadly accepted relations (such as wavelength-frequency conversion) from unverified paper-specific performance claims. Technical ideas that apply to electronic surveillance are taught here using **synthetic signals, public science, and authorized laboratory settings**, not interception of private communications or live tactical emitter profiles.
